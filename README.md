# ⚔️ REBOUND

> *“Fall. Fight. Rise Stronger.”*

A fast-paced 2D action platformer built in **Godot 4** for **Hack Club Haven**.

---

## 📖 About the Game
Long ago, the kingdom was protected by the ancient **Core of Rebound**—an artifact that converted incoming destruction into boundless energy. When the Chief Guardian corrupted the Core, reality fractured into the Shadow Catacombs, Molten Bastion, and Void Spire.

You awaken as a fallen knight stripped of your former power, but bound to a strange magical reaction: **Every impact, knockback, and blow you absorb fuels your counter-attack.** 

Conquer the guardians, claim the sacred Keys, and restore the Core of Rebound!

---

## 🕹️ Controls

| Action | Primary Key | Secondary Key |
|---|---|---|
| **Move Left / Right** | `A` / `D` | `Left` / `Right` Arrow |
| **Jump** | `W` / `Space` | `Up` Arrow |
| **Sword Attack** | `J` | `Z` |
| **Heavy Hammer Smash** | `I` | `X` |
| **Parry / Kinetic Deflect** | `L` | `K` |
| **Shadow Dash** | `F` | `Shift` |
| **Piercing Thrust** | `E` | - |
| **Overdrive Burst** | `C` | - |
| **Pause Menu** | `ESC` | - |

> 💡 **Combat Tip**: Time your Parry (`L` / `K`) right as an enemy strikes to execute a **Perfect Parry**—negating damage, healing **+6 HP**, and granting **+35 Rebound Energy**!

---

## 🌟 Key Features
- **Rebound Combat System**: Taking hits and parrying charges your Core Energy gauge to unleash devastating radial bursts.
- **3 Handcrafted Levels**:
  - *Stage 1: Shadow Catacombs* (Flying Skulls, Wisps, Spikes)
  - *Stage 2: Molten Bastion* (Slimes, Void Eyes, Chasm Platforming)
  - *Stage 3: Void Spire* (The Shadow Knight Boss Encounter)
- **Second Chance Mechanic**: Lethal damage triggers an emergency kinetic pulse, reviving you at 30 HP.
- **Retro Arcade Aesthetics**: Pixel-perfect fonts (*Silkscreen* & *Press Start 2P*), cinematic screen shake, and visceral combat audio.
